# CodeAlpha Sudoku Solver

A C++ based Sudoku Solver developed as part of the **CodeAlpha C++ Programming Internship**.

## Task Description

This program solves a standard 9×9 Sudoku puzzle using a backtracking algorithm. It checks whether numbers can be placed while following Sudoku's row, column, and 3×3 subgrid constraints.

## Features

- Represents the Sudoku puzzle using a 2D array
- Checks row constraints
- Checks column constraints
- Checks 3×3 subgrid constraints
- Uses a recursive backtracking algorithm
- Displays the solved Sudoku puzzle

## Technologies Used

- C++
- 2D arrays
- Recursion
- Backtracking algorithm

## How to Run

1. Open the C++ source file in a C++ compiler or IDE.
2. Compile the program.
3. Run the program.
4. The Sudoku puzzle is processed by the solver.
5. The solved puzzle is displayed if a solution exists.
